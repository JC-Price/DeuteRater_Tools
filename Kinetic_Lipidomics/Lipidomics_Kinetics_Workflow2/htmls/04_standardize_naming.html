Standardizing Polarity Syntax (Positive + Negative)

Goal

When lipid species are measured in both positive and negative ionization modes under identical chromatographic conditions, they elute at the same retention time but may be reported under different identifiers. These identifiers reflect the degree of structural information that can be resolved in each polarity, as positive and negative modes produce different, polarity-specific fragment ions. This step standardizes lipid naming across polarities so that all adduct forms of a lipid map to a single, unified identifier, with the most structurally informative (longest) identifier retained.

Result: Positive- and negative-mode entries referring to the same lipid share the same Lipid Unique Identifier, enabling a single kinetic trajectory downstream. In addition, the herein canonical retention time of the chosen representative is written back to all matched rows.

Naming Standardization Rules (this only works with MS-Dial lipid ID syntax)

  1. Sum Composition Derivation
    The Sum Composition is derived as follows:
    • If Lipid Unique Identifier contains a newline, use the substring before the first newline (\n).
    • Else if Lipid Name is present, use that.
    • Else use the full Lipid Unique Identifier.
  2. Two-Phase Standardization
    Standardization occurs in two steps:
    • Within-mode: For each mode (POS and NEG) separately, rows are grouped by Sum Composition and then clustered by a sliding window in Precursor Retention Time (sec). Within each cluster, the longest Lipid Unique Identifier is selected, and its identifier and retention time are written back to all rows in that cluster.
    • Across modes: For compositions present in both modes, POS+NEG rows are combined and clustered by the same retention-time window. The canonical (longest) identifier and its retention time are then written back to both POS and NEG rows in the cluster.
  3. Cross-Polarity Matching Criteria
    Positive- and negative-mode lipids are eligible for merging if:
    • Their Sum Composition is identical; and
    • Their Precursor Retention Time (sec) differs by ≤ overlap time seconds.
  4. Canonical Identifier & RT Selection
    When a matched set is found (within a mode or across modes), the more descriptive identifier (the longest string) is selected. The chosen identifier and its retention time are written back to all rows in the set.

Other Pre-processing Steps

  • D7 standard detection: Rows with cf containing D7 are labeled D7-standard = True.
  • Deuterium normalization: All deuterium (D) atoms are merged into hydrogen (H) counts in cf and Adduct_cf.
  • Formula cleanup: A single consolidated hydrogen count is retained; redundant H/D tokens are removed.

Why This Step Exists

  • Prevents duplicate lipid identities across polarities
  • Ensures all adducts contribute to a single kinetic model
  • Preserves the most informative lipid annotation

Inputs and Outputs

  • Inputs:
    • Positive-mode CSV
    • Negative-mode CSV
  • Outputs:
    • Positive-mode CSV with standardized identifiers and unified RTs
    • Negative-mode CSV with standardized identifiers and unified RTs

Required Columns

The script expects the following columns to be present in each CSV:

  • Lipid Unique Identifier (and optionally Lipid Name for deriving Sum Composition)
  • Precursor Retention Time (sec) (the script will derive Precursor Retention Time (min) if missing)
  • cf (for D7 detection and D→H normalization); Adduct_cf is optional but will also be normalized if present

User Configuration

The only user-configurable parameter is overlap time, the retention-time tolerance (in seconds) used for within-mode and cross-polarity matching.

Default: 8 seconds.

Recommended selection:

  1. Compare a matched positive/negative run.
  2. Identify the RT gap separating identical versus distinct lipids.
  3. Set overlap time to avoid false merges while preserving true matches.
