Merge Rates & Fraction‑New into a Wide Metabolic Table (Assembly Step)

Purpose in the workflow

This step assembles the core kinetic outputs and identifiers into a single master table that the downstream notebooks and plotting scripts use for statistics and visualization. Concretely, it merges Fraction‑New and Rates outputs from DeuteRater with the polarity‑aware Concatenated ID table from earlier steps (MS‑DIAL → IsobarHandler → standardization).

The result (merged_results.csv) is a consolidated, mostly wide-format dataframe that contains: (i) per‑group Fraction‑New metrics (pivoted), (ii) per‑group Rates metrics (pivoted where possible), (iii) one abundance column per mzML file derived from DeuteRater, and (iv) IDs/metadata carried forward for accurate linking and filtering. Subsequent steps (outside this script) perform summary statistics, multiple testing corrections, and figure generation.

What this script actually does

The helper automates three inputs → one output, with robust joins and reshaping:

  1. Prompts for group codes (comma‑separated; used to form wide columns for group‑specific metrics).
  2. Loads three tables:
    • Fraction‑New (TSV/CSV/Excel)
    • Rates (TSV/CSV/Excel)
    • Concatenated ID file (CSV/TSV/Excel) assembled from POS/NEG concatenation
  3. Builds DeuteRater abundance‑per‑file columns from abundances + mzml_path, producing one column per mzML like Abundance_{FILENAME}_DR.
  4. Fraction‑New long→wide pivot:
    • Melts selected FN metrics (e.g., n_value, BA_rate, BA_Asyn, n_value_SE, bootstrap diagnostic fields, etc.) by sample_group.
    • Rebuilds a wide table with columns suffixed by group (e.g., BA_rate_A2), while keeping null_bootstrap_* fields unsuffixed.
    • Re‑attaches identifier/formula columns and DR abundance columns where present.
  5. Rates wide pivot (if available):
    • Pivots selected numeric (and selected list‑like) rate fields by group when group_name is present.
    • Falls back to the raw Rates table if a pivot is not possible.
  6. Merges (outer/left as appropriate) to produce the master table:
    • Fraction‑New ↔ Rates by Lipid Unique Identifier (FN) ↔ analyte_id (Rates).
    • Then Fraction‑New ↔ Concatenated IDs by Alignment ID.
  7. Canonicalizes overlapping columns introduced by merges:
    • Prefers and renames Lipid Unique Identifier_x → Lipid Unique Identifier; drops the _y variant.
    • Same for Formula and nH (prefers _x where both exist).
    • Safely drops other merge‑created _x/_y columns while protecting true data columns like rate_graph_time_points_x and normed_isotope_data_y.
  8. Ensures nH is present; if missing, derives it from Adduct_cf hydrogen count.
  9. Writes the output as merged_results.csv in the Fraction‑New file’s directory.

This script does not compute medians, RSD, BH‑FDR, or new confidence intervals. Those statistics are performed in downstream analysis notebooks/tools that consume merged_results.csv.

Inputs

  • Fraction‑New table (TSV/CSV/Excel) with columns including:
    • Lipid Unique Identifier, Alignment ID, sample_group, and metric columns such as n_value, BA_rate, BA_Asyn, n_value_SE, and diagnostic bootstrap fields where present.
    • mzml_path and abundances (for per‑file DR abundance columns; if absent, those columns are skipped).
  • Rates table (TSV/CSV/Excel) with:
    • analyte_id (joins to FN’s Lipid Unique Identifier), optional group_name for pivoting, and numerical/list fields the script carries through.
  • Concatenated ID file (CSV/TSV/Excel) with:
    • Alignment ID (joins back to FN), and identifiers like Lipid Unique Identifier, Formula, Adduct_cf, etc., carried from earlier steps.

Outputs

  • merged_results.csv — a consolidated table that:
    • Contains per‑group, pivoted Fraction‑New metrics and (where possible) per‑group Rates metrics.
    • Includes one DeuteRater abundance column per mzML file: Abundance_{FILENAME}_DR.
    • Is keyed by Alignment ID and includes canonicalized identifiers and metadata for downstream stats & plotting.

How to run

  1. When prompted, enter your experiment/group codes, e.g., A2,A3,A4.
  2. Select your Fraction‑New table.
  3. Select your Rates table.
  4. Select your Concatenated ID file.
  5. Wait for confirmation; the script writes merged_results.csv next to the Fraction‑New file.
