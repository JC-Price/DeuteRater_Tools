Lipidomic Kinetics — Comparative Regression Analysis

Purpose

This module performs per‑metric linear modeling on your tidy dataset in order to quantify associations between lipid metrics (e.g., Abundance, Rate, Asymptote) and experimental covariates (e.g., genotype, sex, treatment). For each metric, it fits an OLS model with explicit effects (Sum) coding and an intercept representing the grand mean, then exports coefficient tables, ANOVA, and diagnostic forest plots.

How it runs (interactive)

  1. Choose a confidence interval in a small dialog (90%, 95%, 99%, or custom). The CI level is applied to coefficient intervals and plot annotations.
  2. Select a tidy CSV that contains at least metric and value (plus your predictors). Results are written to a uniquely named output folder next to the CSV.
  3. Run scope: models are run once on all rows and, if an Ontology column exists, again for each ontology value in its own subfolder.

Predictor types are normalized automatically: objects convertible to numeric become numeric; otherwise they are treated as categorical. Predictors with no variation inside a metric subset are dropped before fitting.

Model specification

  • Formula: value ~ 1 + C(cat, Sum) + numeric per metric, where 1 is the intercept (grand mean) and C(cat, Sum) gives effects (Sum) coding. Numeric predictors are added when they vary within the subset.
  • Estimation: OLS via statsmodels, plus an optional HC3 robust covariance variant; both summaries can be written.
  • ANOVA: Type‑II ANOVA (based on the OLS fit) is exported for each metric.
# Example (auto-generated)
value ~ 1 + C(genotype, Sum) + sex + age

Columns intentionally excluded from modeling include: Alignment ID, metric, value, sample_id, ci_lower, ci_upper, Ontology, and se. You can still run per‑Ontology analyses via the automatic split, but Ontology itself is never used as a predictor.

Diagnostics & visualization

  • Forest plots with the chosen CI: points for non‑intercept terms only, a vertical reference at 0, and a numbered key mapping points back to readable term labels.
  • Implied level reconstruction for Sum‑coded categoricals: if a factor has k levels, the (k‑1) reported coefficients are augmented with a computed “missing” level (negative sum of shown levels), including SE and CI—so every level appears in the plot/key.
  • Readable equation is printed at the top in monospaced text; an intercept value ± CI (or [L,U]) appears near the bottom alongside the list of categorical predictors included in the model.

Outputs

  • OLS summary per metric (_ols_summary.txt); optional HC3 summary (_robust_summary.txt).
  • ANOVA Type‑II table (_anova.csv).
  • Coefficient forest plot PNG (_coeff_forest.png) with numbered key, implied level(s), and a human‑readable equation.
  • Error log (_errors.txt) if any metrics fail checks, have too few rows, or run into fitting issues.
  • Scope: one set under all rows, and one set per ontology value if the column exists.

Minimum data & guardrails

  • A metric subset must retain a minimal number of rows after NA‑drop; otherwise it’s skipped with a note in the errors file.
  • Predictors that are constant within a metric subset are removed automatically prior to fitting (prevents singular designs).
